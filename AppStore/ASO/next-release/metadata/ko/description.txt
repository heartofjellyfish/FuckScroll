SNS를 잠깐만 보려다 또 시간이 훌쩍 지났나요? 앱마다 한도를 정해 보세요. 시간이 차면 오리가 앱을 막고 쉬는 시간을 지켜 줘요.

• 앱마다 사용 한도와 휴식 시간을 따로 설정하세요.
• 짧게 여러 번 열어도 합산돼요. 충분히 쉬면 스크린 타임이 업데이트될 때 새로 시작해요.

• 휴식 문구와 나가기 버튼의 글을 직접 쓰세요.
